## ✨ Features

- **Resume Builder** — Personal Info, Summary, Experience, Education, Skills, Projects
- **3 Professional Themes** — Classic, Modern, and Creative layouts
- **Live Preview** — Resume updates in real-time as you type
- **Resume Score** — Strength analysis with improvement tips for each section
- **🔥 AI Resume Roast** — Brutally honest feedback powered by Google Gemini AI
- **⬡ ATS Checker** — Paste any job description and see your keyword match score
- **⎙ PDF Export** — Download your resume as a print-ready PDF
- **Privacy-first** — Email, phone, location are never sent to AI

## 🚀 How to Use

### Step 1 — Open the app
Go to 👉 **[https://devansh-here.github.io/folio](https://devansh-here.github.io/Folio/)**

No installation. No sign-up. Just open and start building.

Use the left panel to fill in your Personal Info, Summary, Experience, Education, Skills, and Projects. Your resume updates live on the right.

Choose between **Classic**, **Modern**, or **Creative** from the toolbar.

### Step 4 — Export your resume

## 🤖 Using the AI Roast Feature

The AI Roast gives you brutally honest, actionable feedback on your resume — powered by **Google Gemini AI (free)**.

### Get your free Gemini API key (one-time setup):
1. Go to **[aistudio.google.com](https://aistudio.google.com)**
2. Sign in with your Google account
3. Click **"Get API Key"** → **"Create API Key"**
4. Copy the key

### Use it in Folio:
1. Click **🔥 Roast My Resume** in the toolbar
2. Paste your Gemini API key in the field
3. Read the privacy notice and tick the consent checkbox
4. Hit **🔥 Roast Me (I Can Take It)**

> 🔒 Your API key stays in your browser only. It is never stored or sent anywhere except directly to Google's API.

### Gemini Free Tier Limits:
| Limit | Amount |
|---|---|
| Requests per day | 1,500 |
| Tokens per minute | 1 million |
| Credit card required | ❌ No |

## 📁 For Developers

Want to self-host or contribute?

```bash
git clone https://github.com/yourusername/folio-resume-builder.git
cd folio-resume-builder
open index.html   # That's it — no npm install, no build step
```

### Deploy on GitHub Pages:
1. Push to GitHub
2. Go to **Settings → Pages**
3. Source: `main` branch, `/ (root)`
4. Live at `https://yourusername.github.io/folio-resume-builder`
